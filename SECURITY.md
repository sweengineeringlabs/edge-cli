# Security Policy

## Reporting Security Vulnerabilities

If you discover a security vulnerability in the edge CLI, please email security@sweengineeringlabs.io with details of the vulnerability.

Please do **not** open a public issue for security vulnerabilities.

## Supported Versions

The latest version of the edge CLI is supported. Security updates will be released as needed.

## Dependencies

This project uses:
- `clap` for CLI argument parsing
- `tracing` for structured logging
- `toml` for TOML parsing
- `serde` for serialization
- `walkdir` for directory traversal
- `thiserror` for error handling

All dependencies are regularly updated and audited for vulnerabilities.
